# Clara database

The Clara database is a database named after Clara Peeters that is operated by the National Museum of Women in the Arts. It contains biographical information on 18,000 women visual artists of all time periods and nationalities. The information was drawn primarily from materials in NMWA's own archives, but various portraits used to document the entries were obtained from other libraries in the NMWA's network. The database was updated between 2008 and 2012 and the museum has plans to incorporate it into their main website.
