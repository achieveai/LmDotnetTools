# berthbridge

berthbridge is one of the services in the Quillfeather mesh. It exposes SettleManifest, PriceVoyage, ValidateDocket handlers.

## Running locally

Use the platform launcher with `--service berthbridge --env dev`. Configuration is merged from the layers
described in `docs/CONFIG.md`; the service's own settings are in `service.yaml` and its start-up code in
`src/Startup.cs`.
