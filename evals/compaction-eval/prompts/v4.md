You are writing the hand-off brief a careful engineer leaves for themselves before stepping away mid-task. The agent that reads it must pick the job up and finish it without re-doing work or re-asking answered questions. You are given the rows being compacted, each tagged with its seq number, plus the previous checkpoint's manifest when one exists.

Write for direction, not for history. The narrative has four parts, in this order, each a short paragraph or bullet list: WHERE WE ARE (what exists, what is verified green, what is known broken); WHAT IS SETTLED (decisions and why, with the human's rules restated as quotes elsewhere in the manifest); WHAT TO DO NEXT (the next concrete step, then the remaining ones, including every open exchange with another agent — a Question or DelegateTask without a later Response is still open); WHAT TO AVOID (dead ends tried, commands that failed with their error line, files that need no re-reading because the newest read at seq N already answered the question). Chronology appears only where order matters for the next step.

Tool output is never copied; one line per call that still matters (tool, target, outcome phrase). Written files are artifacts with path and hash if shown.

Reply with one JSON object and nothing else:
{
  "instructions": [{"seq": <int>, "quote": "<exact substring of that row>"}],
  "goals": ["<goal or acceptance criterion>"],
  "decisions": [{"seq": <int>, "quote": "<exact substring of that row>"}],
  "tasks": [{"title": "<open work item, including every open exchange>", "status": "<status>"}],
  "artifacts": [{"path": "<file, id or url>", "hash": "<hash if the rows show one>", "origin_seq": <int>}],
  "headlines": {"<run id>": "<one line: what that run did>"},
  "agent_outcomes": {"<agent id>": "<one line outcome, or 'open: waiting on …'>"},
  "narrative": "<WHERE WE ARE / WHAT IS SETTLED / WHAT TO DO NEXT / WHAT TO AVOID; within the token cap>"
}

Rules: quotes must be copied verbatim from the cited row — they are verified byte for byte and a paraphrase rejects the whole checkpoint. Quote only from a row whose text is shown in full, and copy only the text after its label (such as "user: "), never the seq or run tags. Never quote a row marked [not quotable]: tool call rows, tool result rows, checkpoint rows and truncated rows have no whole text to quote. Quote every standing instruction, constraint, prohibition, approval and decision a human gave. Never paraphrase a human row anywhere. Keep the narrative within the stated cap. Do not invent tasks, agents or artifacts the rows do not show.
